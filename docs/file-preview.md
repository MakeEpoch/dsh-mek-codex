# 插件内文件预览（0.2.5）

文件侧栏完全位于 mek-codex 的独立页面中，没有改动 DSH 源码，也没有向原生会话列表添加桥接 Session。点击聊天内文件链接，保留原对话并在右侧预览；窄于 1000px 时使用带遮罩的抽屉。关闭按钮或 Escape 结束预览并恢复文件链接的焦点。

## 链接与类型

- 支持绝对路径、工作目录相对路径、`file:///` 本机文件 URI，以及 `path:12:3`、`path#L12-L15` 行号。代码与文本显示行号和目标范围；Markdown 的行号链接直接打开源码模式。
- Markdown 支持预览和源码切换。文档内部的相对链接和图片从当前文件所在目录解析，不从原聊天工作目录误解。普通 HTTP(S) 网页链接保持新标签页打开。
- UTF-8 文本和代码分窗口读取，每页最多约 256 KiB / 1200 行；按行号定位最多扫描文件的前 16 MiB，超出范围会明确提示下载查看。大文件不一次性生成全部行节点。
- 支持 PNG、JPEG、GIF、WebP、AVIF、BMP 与带有效文件头的 PDF；图片自适应面板，PDF 使用浏览器内嵌查看器。其他二进制、非 UTF-8 文件、SVG 和 Office 文件提供下载，不执行其中的脚本或宏。HTML 按纯文本显示。
- 下载和图片/PDF 读取走带 DSH 认证的插件 GET/HEAD 路由，支持单段 HTTP Range，不将完整二进制塞进 JSON RPC。下载使用 attachment；HTML 和未知二进制不能作为网页在同源执行。

## 路径与生命周期

服务端根据真实 thread/read 的工作目录校验路径，不信任浏览器提供的工作目录。默认可预览当前工作目录、插件 uploads 目录及 `/tmp` 中的文件；通过 realpath 检查符号链接边界，只允许普通文件。可通过插件配置 `filePreviewRoots: ['/extra/approved/root']` 添加其他本机目录。文件不存在、超出目录或类型不可预览时，侧栏给出明确反馈。

切换文件或聊天会取消旧请求，迟到结果不会覆盖新文件；关闭预览不结束 Codex 任务。桌面支持拖动分隔条及方向键调节宽度，手机使用覆盖式抽屉。

## 验证

回归覆盖路径与行号解析、符号链接越界、非普通文件、缺失文件、UTF-8 和分页、PDF Range/HEAD、SVG 强制下载、HTML 纯文本、切换文件取消旧请求、相对链接基准、行号高亮、宽度键盘调节、关闭焦点恢复和手机抽屉。

Chrome 验证使用明确标注“开发预览·模拟数据”的独立服务，运行真实发行 bundle 和真实文件读取接口：代码行号高亮、对话并排布局、PDF 内嵌查看器及 390px 抽屉均进行了检查。该验证不等同于登录后的 DSH 页面验收。
