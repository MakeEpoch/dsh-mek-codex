# 输入区交互

- 左侧加号打开图片、排队发送和查看队列；支持粘贴图片。
- 审批胶囊打开“请求批准 / 帮我批准”。新会话默认请求批准；只有用户选择后才通过 `thread/settings/update` 切换 `approvalsReviewer`，不修改 sandbox 或 approvalPolicy。选择保存在该聊天的插件记录中，重新接入时沿用。已有待审批请求时先处理请求，再切换模式；进行中的轮次不追溯切换。
- 模型和推理档在输入区上方的菜单中选择，只展示服务端提供的模型与档位。单独修改审批方式或推理档不清空其他设置；更新失败时不改变选中项。重新打开页面从 presence 恢复已接入聊天的设置。
- 菜单支持点击外部、Escape 关闭以及方向键导航。输入区保留 Enter 发送 / 运行中补充、Shift+Enter 换行与输入法组合输入保护；发送和中断按钮占据同一位置。

## DSH 语音输入

复用 DSH 的 `remote.speech`，读取 `catalog()` 中已选择的 provider、language、准备状态和录音限制。浏览器录音转换为 16 kHz 单声道 PCM16 WAV，交给同一服务的 `transcribe()`；不引入独立语音服务或浏览器语音识别兜底。

点击麦克风开始，完成录音后转写并追加到现有草稿，由用户确认发送。录音、转写期间不会用 Enter 提前发送原草稿。取消、切换聊天或卸载会停止录音并取消请求，迟到的转写不会填入其他聊天。没有启用语音插件、模型未准备好或麦克风不可用时显示原因和 DSH 语音设置入口，不自动下载模型。

## 临时思考摘要

只显示当前 live 轮次中正在输出的那一段摘要，默认展开。该 item 完成、后续工作开始或整个轮次结束后移除；完成后的迟到 delta 不会让摘要重新出现。历史摘要不生成折叠条，也不分隔连续工具组。原始 Codex 记录保留，摘要与原始 reasoning content 仍分开处理。

## 验证边界

协议字段参考本机 Codex 生成的 schema，以及 [官方 App Server 文档](https://learn.chatgpt.com/docs/app-server)。DSH 语音请求遵循已安装语音插件的 Remote 接口。

组件、状态流和录音取消使用模拟数据测试；浏览器布局使用独立临时预览。未通过真实录音或真实模型轮次验收，也不代表已安装插件已更新。
