# 当前聊天自动同步与状态核实（0.2.4）

## 问题与验证

旧版只在打开历史预览时拉取记录，实时事件则来自插件独立启动的 app-server。2026-11-01 对同一真实聊天核实：原生 Codex 连接返回 active / inProgress，独立 0.165.0 app-server 和本机 0.166.0 共享 daemon 均返回 notLoaded / interrupted。两者都能读取历史，却不持有该聊天的运行实例。机器上存在一个共享 daemon，不代表它持有所有桌面或 SSH 聊天。

0.2.4 真实只读验收读取到这条聊天的最新轮次已有 607 个条目；在未接通执行实例时返回 source=history、verified=false、state=unknown，保留原始 recordedStatus=interrupted，但界面不将其显示为当前已中断。连续未变化读取省略正文；验收未 resume 或控制这条聊天。

## 同步路径

- 当前聊天完成初次加载后，每 3 秒串行调用 sync；恢复前台或窗口聚焦时立即核对。后台页暂停拉取正文，失败退避至最多 15 秒，切换聊天与卸载会取消请求并屏蔽迟到响应。
- 本面板已明确接入的聊天继续使用自身事件流；快照用于补齐漏掉的终态和历史。外部聊天可读取本机共享实例的 thread/read；只有返回 active、idle 或 systemError（已加载状态）时，才采用其运行结论及历史内容。
- 共享实例未加载该聊天或连接失败时，回退原始历史，只显示“实时运行状态未核实”。这不是完整的跨实例 token 流；更新速度还受原客户端写入历史的时机影响。
- 每次只同步最新两轮，与已加载记录按轮次 ID 原位合并，不清空旧历史；相同修订不重传正文。历史文件未变化时复用解析结果，内存中的共享聊天仍持续核对。服务端同一聊天的重叠请求合并，缓存最多保留 8 个聊天。
- 已核实外部运行时，“继续此聊天”暂不可用，审批和输入由原客户端处理。观察与控制分离，turn/item 事件不能授予 owned 权限。

## 连接与权限

默认观察 `$CODEX_HOME/app-server-control/app-server-control.sock`，CODEX_HOME 缺省为 `~/.codex`。使用 WebSocket over Unix socket，独立于插件自己的写入运行时；不启动、停止或升级共享 daemon。

可在插件配置中显式指定实际执行实例暴露的受支持 socket：

```yaml
observerSocket: /absolute/path/to/app-server.sock
observerTimeoutMs: 1500
```

设置 `observerSocket: false` 可关闭共享观察，仅保留历史自动更新。连接必须是实际 app-server 的 WebSocket Unix socket；桌面内部 IPC、浏览器控制 socket 和旧版其他传输协议不能混用。不会自动扫描或注入这些私有入口。

观察连接只允许 thread/read 和 thread/turns/list；不调用 thread/resume、turn/start、turn/interrupt 或审批。若收到意外的服务端交互请求，只关闭观察连接，不代替原操作者作答。配置与消息内容不写入浏览器列表缓存。

## 当前边界与后续接入

本机默认共享 daemon 未持有截图中的原生桌面聊天，当前部署对它使用历史自动更新并显示状态未核实。没有声称已经连接该原生实例的实时事件通道。未来若桌面、SSH 与面板连接同一个受支持执行实例，可配置该入口核实运行状态；现有本面板任务仍有原有 turn/item 推送。无需为浏览而迁移或重启正在运行的原生聊天。

## 回归

覆盖独立历史的误中断、共享实例实时快照与终态、断线撤下运行结论、修订检查、重叠请求去重、真实 Unix socket 读连接与重连、拒绝观察连接写方法、意外交互不代答、前台恢复、切换聊天迟到响应隔离、历史合并、外部运行不显示输入框，以及事件回放不能取得控制权。

组件和 socket 测试使用模拟数据。真实验收仅执行只读同步链路，未生成模型任务；登录后的 DSH 页面验收另行区分。
